# JLMAKEUP — versão para publicar grátis + Mercado Pago

Esta pasta já está preparada para:
- hospedagem gratuita no Netlify;
- endereço gratuito `nomedaloja.netlify.app`;
- carrinho;
- Checkout Pro do Mercado Pago;
- Pix, cartões, boleto e outros meios que o Mercado Pago disponibilizar para sua conta/cliente.

## IMPORTANTE
NUNCA coloque seu Access Token dentro do arquivo `index.html`.
NUNCA envie seu Access Token por WhatsApp ou em uma página pública.

A credencial fica protegida no servidor do Netlify através da variável:
`MP_ACCESS_TOKEN`

## Etapa 1 — Conta Mercado Pago
Você precisa de uma conta de vendedor no Mercado Pago.

No painel de desenvolvedores do Mercado Pago:
1. crie uma aplicação;
2. obtenha a credencial de PRODUÇÃO chamada Access Token;
3. copie o token apenas para configurar no Netlify.

## Etapa 2 — Publicar no Netlify gratuitamente
Para esta versão com pagamentos, publique o projeto através de um repositório GitHub conectado ao Netlify.

Estrutura que precisa permanecer igual:
- index.html
- sucesso.html
- pendente.html
- falha.html
- netlify.toml
- netlify/functions/create-preference.js

## Etapa 3 — Configurar o Access Token no Netlify
No painel do site no Netlify:
1. abra as configurações do projeto;
2. procure Environment variables / Variáveis de ambiente;
3. crie a variável:
   MP_ACCESS_TOKEN
4. cole o Access Token de PRODUÇÃO do Mercado Pago;
5. faça um novo deploy.

O token NÃO aparece no código enviado aos clientes.

## Etapa 4 — Testar
Faça primeiro uma compra de valor baixo.
Confirme:
- carrinho correto;
- redirecionamento ao Mercado Pago;
- pagamento aprovado;
- retorno para sucesso.html;
- venda aparecendo na sua conta Mercado Pago.

## Custos
A hospedagem do Netlify possui plano gratuito.
O endereço `.netlify.app` também pode ser usado sem comprar domínio próprio.
O Mercado Pago não exige mensalidade de integração, mas cobra tarifa por transação/venda conforme o meio e prazo de recebimento.

## Observação importante para uma loja completa
Esta versão já cria cobranças reais, mas uma operação de e-commerce completa também deve ter:
- cadastro/endereço do comprador;
- cálculo de frete;
- política de troca/devolução e privacidade;
- estoque sincronizado;
- confirmação automática do pedido;
- webhook para atualizar status do pagamento;
- painel de pedidos.

Essas partes podem ser adicionadas depois sem jogar fora o visual atual.
